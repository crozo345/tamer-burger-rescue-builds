# TAMER EL GAYAR: The Burger Rescue — Android builds

Download the APK from the [Releases](releases) page and install it on an arm64 Android phone or tablet.

## Notes
- The build is **debug-signed** with Godot's own debug key, so Android will warn about installing from an unknown source. That is expected for a personal build.
- Requires **Android 8+** and an **arm64** device.
- Contents: 5 levels (Burger Town, Eggplant Forest, Prison Factory, Eggplant Fortress, Final Rescue), three Eggplant enemy types, the Burger rescue chain, Egyptian Arabic voice acting, and the original Tamer character mesh.

## Known gaps
- Not yet tested on a physical phone. The Android emulator cannot load the 3D scene on the development machine, so all verification so far is desktop.

To remove a build: delete the release, then delete this repository.
